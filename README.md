# TASPC

## Target-Adaptive Spatial-Spectral Prototype-Cache Modeling for Zero-Shot Hyperspectral Image Classification

TASPC is a research project for strict zero-shot hyperspectral image classification.

The work investigates how unlabeled target-domain information can be utilized at inference time to reduce the mismatch between semantic knowledge and unseen visual distributions, while keeping the backbone model unchanged.

---

## Main Results

TASPC was evaluated on four public hyperspectral image datasets under the strict zero-shot setting:

- Houston 2013
- Indian Pines
- Pavia University
- WHU-Hi-LongKou

Compared with the second-best competing method on each dataset, TASPC improves overall accuracy (OA) by:

| Dataset | OA Improvement |
|---|---:|
| Houston 2013 | +3.91 pts |
| Indian Pines | +5.97 pts |
| Pavia University | +3.17 pts |
| WHU-Hi-LongKou | +3.43 pts |

The method achieves the best overall performance across the evaluated datasets.
